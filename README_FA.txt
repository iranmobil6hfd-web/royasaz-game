Dream Builder - پروژه اندروید

این پوشه پروژه قابل باز کردن در Android Studio است.
برای ساخت APK:
1) Android Studio را نصب کنید.
2) این پوشه را با گزینه Open باز کنید.
3) صبر کنید Gradle و Android SDK نصب/همگام‌سازی شوند.
4) از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را انتخاب کنید.
5) فایل APK در مسیر app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

نیازمندی‌ها: Android Studio، JDK سازگار و Android SDK Platform 35.
این نسخه آفلاین است و برای بازی دو نفره روی یک گوشی طراحی شده است.
